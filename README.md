#### 一、项目概述

**云棋AI（CloudChessAI）** 是一个以 **Python** 语言开发、基于 **Tkinter** 图形界面框架的五子棋综合应用。项目版本 `Nv1.1`，发布于 **2026年5月4日**。

#### 二、核心AI算法

##### 2.1 棋盘表示

棋盘大小为 **11×11**，采用二维整型数组表示（`0` 为空、`1` 为黑棋/玩家、`2` 为白棋/AI）。

##### 2.2 神经网络模型

AI 的核心决策系统由两个深度卷积神经网络（CNN）构成：

- 🧠 **策略网络（Policy Network）**：输入当前棋盘状态，输出 121 个落子位置的概率分布。经过大量自对弈数据训练，当前策略网络的 **Top-1 准确率达到 `38%`，Top-5 准确率达到 `68%`**，意味着 AI 在绝大多数局面下能将最优解或次优解圈定在极小的范围内。
- ⚖️ **价值网络（Value Network）**：输入当前棋盘状态，输出当前局面的胜率估值（0~1）。当前价值网络的 **均方误差（MSE）已降至 `0.067`**，具备极强的局面评估能力，能够精准判断局势优劣。

> 📦 两个网络均采用卷积层配合残差结构，并经过 Dropout 与 BatchNorm 处理，模型文件为 **pth 格式**（`CCS-PNN.pth` 与 `CCS-VNN.pth`），支持 **GPU 加速**。

##### 2.3 蒙特卡洛树搜索（MCTS）

AI 采用 **AlphaGo 风格**的蒙特卡洛树搜索，结合策略网络与价值网络，并使用 `numpy` 加速：

- 🔍 **选择（Selection）**：使用 PUCT 公式，结合策略网络提供的先验概率与节点的胜率估值，动态平衡探索与利用。
- 🌱 **扩展（Expansion）**：用策略网络输出的概率分布指导子节点的扩展。
- 📊 **评估（Evaluation）**：直接调用价值网络对叶子节点进行评估，替代传统的随机模拟到终局，极大提升搜索效率。
- 🔄 **回溯（Backpropagation）**：将价值网络给出的胜率沿搜索路径回传，更新所有父节点的访问次数与平均价值。

##### 2.4 高级搜索优化

- ⚡ **必胜/必堵检测**：在 MCTS 搜索前，先进行快速的单线胜负判断，若存在一步必胜或对手一步必胜的落点，直接返回结果，避免无效搜索。
- 🧵 **多线程并行搜索**：采用多线程并行执行 MCTS 模拟，配合虚拟损失（Virtual Loss）机制，防止多线程重复探索同一条路径。
- 📈 **FPU 优化**：未访问节点的初始价值采用已访问子节点的平均 Q 值，使搜索更合理。
- 🌡️ **温度参数**：实战对局中使用低温（`0.1`），确保 AI 绝大多数时候选择访问次数最多的最优解。
- 🎯 **对手模型（可选）**：若用户开启该功能，AI 会读取该用户的历史对局数据，统计其走法偏好，并在搜索时对对手常下的位置进行加权，提前布防。

#### 三、功能模块详解

##### 3.1 用户账号系统

- 🔐 **注册与登录**：新用户需提供用户名、密码（必须同时包含字母和数字，长度 ≥5，无特殊符号）和确认密码。密码经过 **SHA-512 加盐哈希**后存入 `YQ_DataBase.json`，即使数据文件泄露也无法还原原始密码。
- 🛡️ **登录保护**：连续登录失败超过 **4 次**，程序自动关闭，防止暴力破解。
- 👤 **账号管理**：登录后用户可以修改昵称、密码、上传自定义头像（自动裁剪为圆形），也可以选择注销账号。注销操作会永久删除该用户的所有个人数据（包括基本信息和历史对局记录），且不可恢复。
- 💰 **云币与等级**：每次对局获胜可获得云币奖励（与难度挂钩），每累计 `100` 云币提升 `1` 级。等级还直接决定解锁残局挑战的数量。

##### 3.2 对战模式

系统提供三种对战模式：

- ⚔️ **AI对战（玩家先手）**：玩家执黑先行，AI 执白后手。
- ⚔️ **AI对战（AI先手）**：AI 执黑先行，玩家执白后手。
- 👥 **双人对战**：
  - 🏠 **线下模式**：两位玩家在同一台设备上轮流落子。
  - 🌐 **联机模式**：一方创建服务器，指定端口号，等待其他玩家连接；另一方输入主机 IP 地址和端口号，主动发起连接。
  
> 🔌 联机对战基于 **TCP Socket** 实现，程序会在后台线程中持续监听对方落子消息，确保对战过程流畅不卡顿。

##### 3.3 残局挑战系统

云棋AI内置了 **40 个**精心设计的残局，按照难度分为四个等级：

| 难度等级 | 残局编号 | 连杀要求 | 解锁等级 |
| :--- | :--- | :--- | :--- |
| 🟢 **简单** | #1～10 | 2～3 步连杀 | Lv.1 |
| 🟡 **中等** | #11～25 | 3～4 步连杀 | Lv.3 |
| 🟠 **困难** | #26～40 | 4～5 步连杀 | Lv.5 |
| 🔴 **大师** | #41～50 | 5～7 步连杀 | Lv.8 |

##### 3.4 成就系统

系统内置了 **12 个成就**，涵盖对局数量、胜场、连胜、击败高难度 AI、联机对局、残局破解、等级提升等各个方面。成就达成条件实时监测用户数据，一旦满足条件即弹出祝贺提示，并自动发放云币奖励。已解锁的成就在个人信息页面中会以 **绿色背景** 和 ✅ 标记显示。

> 🏆 **成就列表**：初出茅庐、百战老将、首胜之光、常胜将军、棋圣降世、破产边缘、AI克星、社交达人、残局高手、残局大师、十连胜、等级飞升。

##### 3.5 历史记录与复盘

每一局对弈结束后，系统都会自动保存以下信息：
- 完整的棋盘局面（以字符串形式存储）；
- 对局日期和时间；
- 对局类型（AI、me、player1、player2、other）。

用户可以在 **“个人信息” → “历史记录”** 中按日期和对手类型筛选历史对局。双击某条记录，会弹出一个棋盘详情窗口，以图形化方式展示当时完整的落子情况，方便复盘分析。用户也可以选择删除单条记录或清空全部历史。

##### 3.6 多语言支持

系统支持 **简体中文** 和 **英文** 两种界面语言，所有界面文本（包括提示信息、按钮文字、菜单项等）均集中存储在 `CCS_CEI.py` 文件中。用户点击语言切换按钮后，程序会销毁当前窗口并重新创建，实现完全的中英文无缝切换。

##### 3.7 关于与技术支持

“关于”页面展示了程序的详细信息：版本号、AI 算法说明、发布时间、前端/后端设计者、赞助商、参考文献等。用户双击“技术支持”或“玩法规则”文本可以查看具体的致谢名单和游戏规则说明。

#### 四、游玩方法与操作指南

##### 4.1 安装与运行

1. 确保所有项目文件保持完整目录结构（即 `CloudChessAI-Nv1.1.exe`、`font/`、`images/`、`files/`、`SourceCode/` 位于同一级目录下）。
2. 直接双击运行 `CloudChessAI-Nv1.1.exe`。
3. 程序启动时会显示一个带有进度条的启动界面，加载完成后自动进入登录/注册主界面。

##### 4.2 注册与登录

1. 首次使用需要点击 **“创建账号”** 按钮，填写用户名、密码和确认密码。
2. 注册成功后返回登录界面，输入用户名和密码，点击 **“登录”**。
3. ⚠️ **注意**：密码不能为空，且必须同时包含字母和数字，长度至少 5 位，不允许出现特殊符号。

##### 4.3 开始对局

1. 登录成功后进入游戏主界面。
2. 在顶部选择 **AI 参数**。
3. 点击五个选项卡之一选择对战模式：
   - **AI对战（您是先手）**：玩家执黑先行。
   - **AI对战（您是后手）**：AI 执黑先行。
   - **双人对战**：进入子菜单选择线下或联机模式。
   - **个人信息**：查看/编辑个人资料、历史记录、成就列表、残局挑战。
   - **关于**：查看版本信息和致谢。
4. 点击 **“开始游戏”** 按钮，棋盘激活。
5. 点击棋盘上黄色交叉点进行落子（黑棋 `●`、白棋 `○`）。
6. 当一方连成五子时，程序弹出获胜提示并自动保存对局记录，随后可开始新的一局。

##### 4.4 联机对战步骤

1. 选择 **“双人对战” → “联机对战”**。
2. 在弹出的对话框中输入**房间号**（如 `12345`）和**房间密码**。
3. 等待对方输入同样的房间号和密码并连接，连接成功后即可开始对局。

##### 4.5 残局挑战步骤

1. 在主界面点击 **“个人信息” → “残局挑战”**。
2. 查看当前等级下已解锁的残局列表。
3. 双击某个残局进入挑战界面，界面上方会显示当前该谁走棋。
4. 按照五子棋规则落子，破解成功会收到提示并获得云币。

##### 4.6 修改个人信息

1. 点击 **“个人信息” → “账号管理” → “修改信息”**。
2. 可以修改头像（从本地选取图片，自动裁剪为圆形）、昵称和密码。
3. 修改完成后程序会刷新界面并更新数据库。
